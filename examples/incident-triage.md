# Incident triage

```sh
qwen-local-incident
```

```text
Analyze the supplied sanitized logs, recent diff, and runbook as an incident investigator. Build a timeline, separate facts from hypotheses, identify the smallest set of discriminating local checks, and rank likely causes. Do not contact external systems. Do not edit until the failure mechanism is demonstrated. If a safe local fix is justified, implement it with a focused regression test and produce rollback and verification steps.
```
